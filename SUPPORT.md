# Support

- **Documentation:** https://reallysec.com/en/docs/signaldesk
- **Bugs and feature requests:** open an issue on this repository
  (https://github.com/reallysec/signaldesk/issues). Please search existing issues first and use
  the issue form; it asks for your version, edition and deployment method.
- **Security vulnerabilities:** do not open an issue; see [SECURITY.md](SECURITY.md).
- **Enterprise Edition and commercial support:** see [EDITIONS.md](EDITIONS.md) and
  https://reallysec.com. Trials and licences: https://console.reallysec.com.

Community support is best-effort; there is no response-time guarantee for issues.
